# 前端页面截图

本目录存放课程设计最终报告要用的页面截图，编号与文件名由 `00_分工与进度.md` 约定，不要自行改名。

## 需要交付的截图

| 文件名 | 页面 | 对应地址 |
| --- | --- | --- |
| `登录页.png` | 管理员登录 | `/login` |
| `书籍列表.png` | 书目查询（带筛选条件与可借副本按钮） | `/books` |
| `借阅历史.png` | 某位读者的借阅记录（含在借/已归还/逾期状态） | `/readers/R001` |
| `统计报表.png` | 四张报表同屏 | `/reports` |

## 截图前的检查

1. 数据库已按 `src/backend/sql/04_init.sql` 建好并导入 `06_测试数据.sql`，页面数据是真实查询结果，不是占位文字。
2. 浏览器窗口宽度不小于 1280，保证表格不折行。
3. 不出现本机真实路径、浏览器账号、真实姓名或密码；演示统一用测试数据里的读者与管理员。
4. 报表面板要把四条口径说明一起截进去，便于报告里解释统计方式。
5. 截图放在本目录，文件名与上表一致；`.png` 直接提交进仓库，不压缩成 zip。
