## 五、注意事项

1. **数据库选型**：当前远程实例实际为 MySQL 9.7.2（任务书写 MySQL 8.4 LTS，差异已记录）；若需严格符合任务书，请切换为 8.4 LTS 或 PostgreSQL 16 并同步调整数据字典
2. **存储引擎**：MySQL 建议用 InnoDB（支持外码 + 事务）
3. **范式**：要求达到 3NF，如果有反范式设计（如冗余字段）必须在数据字典里说明理由
4. **截止日期**：以老师实际公布为准；当前排期最晚至 12/04，若截止日期有变化请同步调整各任务时间
