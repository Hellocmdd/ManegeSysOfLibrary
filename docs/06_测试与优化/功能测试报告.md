## 3. 执行中发现并修复的问题

1. **测试数据基线错误**：`BR003` 的 `borrow_date=2026-10-20`、`due_date=2026-11-19`，在 2026-11-25 已被判为当前逾期，导致当前逾期为 3 条。已改为 `2026-11-20` / `2026-12-20`，基线恢复为 2 条（BR004、BR009）。
2. **排序规则冲突**：存储过程入参与局部字符串变量隐式使用 `utf8mb4_general_ci`，而表列使用 `utf8mb4_unicode_ci`，导致借/还/续全部落入 `-4` 异常分支。已做三处修复：过程入参与局部字符串变量显式 `COLLATE utf8mb4_unicode_ci`；`Borrow.status` 列与 CHECK 字面量显式排序规则；JDBC URL 增加 `connectionCollation=utf8mb4_unicode_ci`。
