## 3. 本地配置

仓库根目录的 `.env.example` 是前后端共用的唯一模板（含数据库与 Flask 配置）。复制并填写密码：

```bash
cd /home/tby/ManegeSysOfLibrary
cp .env.example .env
# 编辑 .env，至少填写 DB_PASSWORD
```

`.env` 已被 `.gitignore` 忽略。程序运行时由 `DBUtil` 优先读取环境变量，其次读取项目根目录 `.env`。

## 4. 连通性验证

### 4.1 MySQL 客户端

```bash
set -a; . ./.env; set +a
MYSQL_PWD="$DB_PASSWORD" mysql --protocol=TCP \
  -h "$DB_HOST" -P "$DB_PORT" -u "$DB_USER" -D "$DB_NAME" \
  -e "SELECT VERSION(), DATABASE(), USER();"
```

### 4.2 Java/JDBC

```bash
mvn -q exec:java -Dexec.mainClass=com.library.util.ConnectionCheck
```

已验证输出：

```text
连接成功
驱动: MySQL Connector/J mysql-connector-j-8.4.0
数据库产品: MySQL 9.7.2
当前库: storageoflibrarysys
SELECT VERSION(): 9.7.2
```

## 5. 目录约定

仓库采用前后端分离结构：

- 后端源码：`src/backend/main/java/com/library/`
- 后端测试：`src/backend/test/java/`
- 前端目录：`src/frontend/`（框架与语言沿用原计划，本次不改动）

## 6. CI 说明

GitHub Actions 只执行编译与测试，不连接远程数据库，因此无需向 CI 配置数据库密码。
