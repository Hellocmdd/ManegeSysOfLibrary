### 2.1 本地 Docker 方案（可选）

仓库根目录 `docker-compose.yml` 提供 `mysql:8.4` 容器，用于对齐任务书版本、离线答辩和重复初始化。关键约定：

| 项目 | 值 |
| --- | --- |
| 镜像 | `mysql:8.4` |
| 宿主机端口 | `${DB_PORT:-3307}` |
| 数据库 | `storageoflibrarysys` |
| 应用用户 | `library`（口令取 `.env` 的 `DB_PASSWORD`） |
| root 口令 | 仅取 `.env` 的 `MYSQL_ROOT_PASSWORD`，不入库 |
| 初始化脚本 | `src/backend/sql/04_init.sql` → `05_存储过程.sql` → `06_测试数据.sql`，仅首次空数据卷执行 |

使用方式：

```bash
# 先把 .env 中 DB_* 改为本地容器参数，并填写两个口令
docker compose up -d
docker compose ps

# 重新初始化（清空数据卷）
docker compose down -v
docker compose up -d
```

已在 Docker MySQL 8.4.13 上完成验证：`docker compose down -v` 后重新 `up -d --wait`，三份脚本自动初始化成功，基线为借阅 15 / 当前逾期 2；Java 真库集成 25/25 通过，前端真库冒烟 1 passed。首次初始化曾因客户端字符集未设置报 `Data truncated for column 'role'`，现已在 `05_存储过程.sql`、`06_测试数据.sql` 及 Java 配套副本开头补 `SET NAMES utf8mb4;`。

## 3. 本地配置

仓库根目录的 `.env.example` 是前后端共用的唯一模板（含数据库与 Flask 配置）。复制并填写密码：

```bash
cd /home/tby/ManegeSysOfLibrary
cp .env.example .env
# 编辑 .env，至少填写 DB_PASSWORD
```

`.env` 已被 `.gitignore` 忽略。程序运行时由 `DBUtil` 优先读取环境变量，其次从当前目录向上查找仓库根目录的 `.env`。

## 4. 连通性验证

### 4.1 MySQL 客户端

```bash
set -a; . ./.env; set +a
MYSQL_PWD="$DB_PASSWORD" mysql --protocol=TCP \
  -h "$DB_HOST" -P "$DB_PORT" -u "$DB_USER" -D "$DB_NAME" \
  -e "SELECT VERSION(), DATABASE(), USER();"
```

### 4.2 Java/JDBC

```bash
mvn -q exec:java -Dexec.mainClass=com.library.util.ConnectionCheck
```

已验证输出：

```text

驱动: MySQL Connector/J mysql-connector-j-8.4.0
数据库产品: MySQL 9.7.2
当前库: storageoflibrarysys
SELECT VERSION(): 9.7.2
```
