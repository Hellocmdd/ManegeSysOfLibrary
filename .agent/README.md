# .agent 工程规范

本目录存放本仓库在开发过程中需要共同遵守的工程规范。

## 规范优先级

1. `docs/大模型辅助数据库设计与JDBC编程_课程大作业.docx`：课程任务书，最高优先级。
2. `.agent/*.md`：本目录的工程规范，不得与任务书冲突。
3. `README.md`、`docs/00_分工与进度.md`：分工与进度说明。前端相关描述保持原计划不动；后端以课程任务书为准。

## 文档索引

- [CODING_STANDARDS.md](CODING_STANDARDS.md)：编码原则
- [DESIGN_GUIDELINES.md](DESIGN_GUIDELINES.md)：设计准则
- [GIT_CONVENTIONS.md](GIT_CONVENTIONS.md)：Git 提交规范
- [AI_USAGE.md](AI_USAGE.md)：AI 辅助使用规范

## 适用范围

本目录规范覆盖**数据库设计与 Java/JDBC 后端实现**。前端实现框架、语言与文件保持原文档中的计划，不在本次规范范围内。

## 变更方式

修改本目录文档时，提交信息需说明依据，例如：

```text
docs(agent): 按任务书补充 JDBC 事务规范
```
